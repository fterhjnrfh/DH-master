当前阶段目标：

1. 回放默认只面向**单个浏览视图**，打开 session 时先给出全时长总览。
2. 首屏总览必须在 `1s` 内返回首屏概览结果。
3. 预览层采用 `L0-L4`：
   - `L0`：原始层
   - `L1-L4`：持久化 preview 层

## 3. 核心原则

1. 文件格式不是快速打开能力的唯一来源
2. 快速打开能力必须来自：
   - `manifest`
   - `catalog`
   - `segment`
   - `channel/time index`
   - `preview files`
3. UI 不直接读文件
4. 回放默认优先走预览层，不先走原始层
5. 首屏总览不允许依赖整通道读取或首次临时重建 preview
6. preview bucket 必须保留包络语义，不能退化成普通抽样点

## 5. 推荐的默认打开流程

1. 打开 `session.catalog.db`
2. 读取失败时回退 `session.manifest.json`
3. 读取 `channel.index` / `time.index`
4. 根据当前浏览窗口选择：
   - 首屏总览默认优先 `L4`
   - 逐级放大按 `L4 -> L3 -> L2 -> L1 -> L0` 下钻
   - `2s` 视窗默认优先 `L1`
5. 返回统一快照

不允许默认流程变成：

- 扫目录
- 打开所有大文件
- 整通道读取

### 5.1 打开流程输入输出表

| 步骤 | 输入 | 输出 |
| --- | --- | --- |
| 读取 manifest | session path | `SessionDescriptor` |
| 读取 catalog | manifest | `SegmentDescriptor[]` |
| 读取 index | window request | `SegmentRange` |
| 读取 preview/raw | `SegmentRange + PreviewLevel` | `CurveWindowSnapshot` |

## 6. 回放策略

### 6.1 单视图

建议默认：

- 首屏总览优先最粗 preview 层
- 随视窗缩小逐级切到更细 preview 层
- `2s` 视窗默认优先 `L1`
- 继续缩小或需要精读时才切原始层

### 6.2 首次打开

建议默认：

- 优先已有预览文件
- preview/index 在采集或转换时同步生成
- 缺失时允许局部懒构建作为兜底，但不作为默认主路径

1. 不允许默认整通道读取后再裁剪。

3. 不允许缺少 manifest/catalog 仍然视为正式会话格式。
4. 不允许把 `2s` 最细视窗直接定义为“必须整段原始数据读取”。
5. 不允许把统计功能所需聚合值留到后续再补，导致 preview 格式返工。

---

## 8. 阶段验收标准

1. 历史会话可以通过 `manifest + catalog + index` 快速打开
2. 回放链默认不再整通道读入内存
3. 查询层可以消费历史索引和预览文件
4. 单浏览视图的首屏总览在代表性会话上必须满足 `1s` 内返回首屏概览
5. `2s` 视窗默认优先命中 `L1`，而不是直接退回原始层

## 8.2 人工验证要求

本阶段至少覆盖以下人工测试场景：

1. 打开完整历史会话
2. 按时间窗跳转
3. 单浏览视图历史总览
4. 鼠标滚轮逐级放大到 `2s`
5. 预览文件缺失后的首次打开
6. 恢复会话打开

每个场景至少验证：

- 是否优先走 `manifest + catalog + index`
- 是否避免整通道读取
- 返回的 `CurveWindowSnapshot` 状态字段是否正确

## 8.3 量化退出门槛

本阶段通过标准：

1. 历史会话默认打开路径必须经过：
   - `manifest`
   - `catalog`
   - `index`
2. 不允许把整通道读取作为默认路径。
3. 首屏总览默认优先命中最粗 preview 层，`2s` 视窗默认优先命中 `L1`。
4. 在代表性历史打开场景下：
   - 首屏概览必须在 `1s` 内返回
   - 首次打开延迟相对无索引方案必须显著下降
   - 具体门槛由本轮 `baselineRound` 记录并冻结
5. 历史回放接入后，已验证显示场景帧率相对批准基线不得回退超过 `5%`。

## 8.4 旧链路退场清单

本阶段应开始冻结以下旧读取路径：

- `TdmsReaderUtil.ReadChannelData()` 整通道默认读取路径
- UI 直接猜目录结构定位会话
- UI 直接扫描大文件做首次打开

允许保留：

- 调试用途的手工读取工具

不允许保留：

- 生产路径继续依赖整通道读取
